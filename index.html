Discover nearby history and folklore, with sources and confidence badges so you can judge each story.

Inside the build & known limits

The build: Offline site data, location alerts, narration, and a browser atlas.

Current limits: GPS alerts are an Android feature. The web atlas needs to stay open for Near me. The map is schematic, and some historical details remain unverified.

02 / creative machinery

WaveForgeVideo

Windows release

Trim, convert, rotate, and resize a video without building an editing project from scratch.

Runs on: Developed and tested on Windows 11. Install FFmpeg separately; the Windows ZIP does not need Python.

Download Windows ZIP ↗
Source & instructions ↗Report a bug ↗
Inside the build & known limits

The problem: Make everyday video jobs easier to complete.

The build: A desktop front end for FFmpeg, with trim controls, previews, conversion, and export logging.

Current limits: One clip at a time. Previews are still frames; there is no multi-clip timeline. Trimming re-encodes video.

DualCast

Send Windows audio to two Bluetooth devices, with separate volume and timing controls.

Download pre-release ↗
Source & instructions ↗Report a bug ↗
Inside the build & known limits

The problem: Share the same audio across two playback devices.

The build: Independent output queues, volume, sync calibration, and session health controls.

Current limits: Streaming to two real devices is still being tested. Bluetooth clocks can drift; calibration or a restart may be needed. DRM audio is not captured.

04 / bridging worlds

VRChat Universal Translator

Early release · Experimental VR features

Read local live captions and English translations of VRChat speech on your Windows PC.

Runs on: Windows 11 x64, Visual C++ 2015–2022 x64 Redistributable, and an initial speech-model download. CPU processing.

Download Windows ZIP ↗
Source & instructions ↗Report a bug ↗
Inside the build & known limits

The problem: Help people follow conversations across languages.

The build: Local speech recognition, translated captions, desktop overlays, and an optional local phone display.

Current limits: Automatic captions can be wrong. SteamVR, phone display, and speaker labels still need full real-device acceptance testing. Independent project; not affiliated with VRChat Inc.
