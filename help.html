A little help getting started.

Free independent software, practical instructions, and honest limits. Here’s where to download, ask a question, or help improve a build.

First time downloading from GitHub?

  1. Choose your project on the work page and open its download button.
  2. Read the release notes and choose the app package under Assets. “Source code” is for building the project yourself.
  3. On Windows, extract the ZIP before opening the program. For Lore on Android, open the APK and follow Android’s installation prompts.
  4. Check any published checksum and review the requirements and known limits. Keep the extracted Windows files together.

You don’t need a GitHub account to download a public release or open the Lore web atlas.

What to expect

These are independent projects. Early releases can have rough edges; the project documentation explains what was tested and what still needs real-device checks.

Bug reports and contributions are welcome. Support has no guaranteed response time. Check each repository’s license for reuse terms.

Help shape the workshop

Five minutes. A fresh pair of eyes.

You do not need to be a developer to help. Try this short check on your phone or computer and tell me what made sense and what did not. Installing an app is optional.

  1. First impression: Open the homepage. In your own words, what does this company do, and who is Alex?
  2. Find a starting point: Pick a project that interests you. Can you tell what it does, what device it needs, and whether it is an early release?
  3. Try one thing: Open the Lore web atlas without installing anything, or read the video-tool walkthrough. Tell me what you tried and where you stopped.
  4. Find the next step: Can you find help for an app and a way to discuss a freelance project?
  5. Tell me one improvement: What was confusing, missing, or harder than it should have been? Include your device and browser if something did not work.

Email your answers to wommper1@gmail.com, or use the website issue tracker. You can send a partial response. Please leave out private information; GitHub issues are public.

Privacy, simply

This static website has no contact form, account system, advertising scripts, or analytics added by us. GitHub Pages hosts the site and handles web requests under GitHub’s privacy statement. Following a link to GitHub, an app, or another service is subject to that service’s practices.

Each app has its own behavior and permissions. Read its project documentation before using it; the website’s privacy description does not replace an app’s privacy notice.

Found an accessibility problem?

Please use the website feedback link above and mention the page, device, browser, and the action that was difficult. Keyboard navigation, readable text, and usable mobile layouts matter here.
